## ⛔ 현재 전 페이지 색인 차단 중 (해제 금지)

`site.config.mjs` 의 **`noindexAll: true`** 때문에 **홈을 포함한 모든 페이지**에
`noindex, nofollow` 가 붙어 있고 `sitemap.xml` 은 비어 있습니다.

이유: 착수 단계라 본문이 전부 자리표시자입니다. 이 상태로 색인되면 **AI가 빈 페이지를
이 회사의 서비스 설명으로 학습합니다. 되돌릴 수 없습니다.**

**이 값을 `false` 로 바꾸는 것은 아키 지시가 있을 때만 합니다. 임의 해제 금지.**

`robots.txt` 는 그대로 둡니다 — 봇의 **방문**은 허용하되 **색인**만 막는 것입니다.

## 도메인 연결 절차 (`aeo.camphive.kr`)

**현재 연결하지 않았습니다.** `camphive.kr` 도메인이 아직 등록되지 않아
(DNS 조회 결과 `camphive.kr` 이 존재하지 않음) 하위 주소를 만들 수 없습니다.

`aeo.camphive.kr` 은 `camphive.kr` 의 하위 주소이므로 **도메인을 새로 사지 않아도** 됩니다.
`camphive.kr` 을 먼저 등록한 뒤 아래 순서로 진행합니다.

### 1단계 — 도메인 등록기관에서 CNAME 레코드 추가

`camphive.kr` 을 구입한 곳(가비아, 후이즈, 카페24 등)에 로그인합니다.
`DNS 관리` 또는 `DNS 설정` 메뉴로 들어가 **레코드 추가**를 누르고 아래를 입력합니다.

| 칸 이름 | 입력할 값 |
|---|---|
| 타입 (Type) | `CNAME` |
| 호스트 / 이름 (Host, Name) | `aeo` |
| 값 / 서버주소 (Value, Target) | `joung2076-cyber1076.github.io` |
| TTL | 그대로 두거나 `3600` |

> 값 끝에 점(`.`)을 붙이라는 곳도 있습니다. 안내에 따르면 됩니다.
> **주의**: 호스트 칸에 `aeo.camphive.kr` 전체를 넣지 말고 `aeo` 만 넣습니다.
> 등록기관이 뒷부분을 자동으로 붙입니다.

저장하면 목록에 `aeo` 줄이 새로 보입니다. **반영에 최대 24시간** 걸립니다.

### 2단계 — GitHub에 도메인 알려주기

`https://github.com/joung2076-cyber1076/camphive-aeo` 접속
→ 위쪽 `Settings` 탭 → 왼쪽 메뉴 `Pages`
→ `Custom domain` 칸에 **`aeo.camphive.kr`** 입력 → `Save`

`DNS check in progress` 가 뜹니다. 1단계가 반영되면 **초록색 체크**로 바뀝니다.
바뀐 뒤 아래쪽 **`Enforce HTTPS`** 를 체크합니다.

> **1단계를 먼저 하십시오.** 순서를 바꾸면 임시 주소(`github.io`)마저
> 접속이 안 되는 상태가 몇 시간 이어집니다.

### 3단계 — BASE_PATH 제거 (빌더가 처리)

도메인이 붙으면 사이트가 주소 맨 앞(루트)에서 열리므로 하위 경로 설정이 필요 없어집니다.
`.github/workflows/deploy.yml` 에서 `BASE_PATH` 줄을 지우면 됩니다. 그 자리에 주석이 있습니다.
