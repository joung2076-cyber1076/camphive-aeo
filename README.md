## ⛔ 현재 전 페이지 색인 차단 중 (해제 금지)

`site.config.mjs` 의 **`noindexAll: true`** 때문에 **홈을 포함한 모든 페이지**에
`noindex, nofollow` 가 붙어 있고 `sitemap.xml` 은 비어 있습니다.

이유: 홈 본문이 아직 자리표시자입니다. 이 상태로 색인되면 **AI가 빈 페이지를
이 회사의 서비스 설명으로 학습합니다. 되돌릴 수 없습니다.**

**이 값을 `false` 로 바꾸는 것은 별도 지시가 있을 때만 합니다. 임의 해제 금지.**

`robots.txt` 는 그대로 둡니다 — 봇의 **방문**은 허용하되 **색인**만 막는 것입니다.

## ⚠ 회사 홈페이지(camphive.kr)와 섞지 말 것

**사이트가 두 개이고 정본 문장이 서로 다릅니다.** 절대 섞어 쓰지 않습니다.

| | 이 사이트 | 회사 홈페이지 |
|---|---|---|
| 폴더 | `홈피제작/aeo/` | `홈피제작/camphive/` |
| 도메인 | aicampingmarketing.co.kr | camphive.kr |
| 성격 | AEO/GEO 마케팅 상품 홍보 | 회사 홈페이지 + 창업 정보 |
| 대상 독자 | **캠핑장 운영자(캠핑주)** | 캠핑장 창업 준비자 |
| 저장소 | `camphive-aeo` | `camphive-site` |
| 우선순위 | **최우선** | 대기 |

**두 사이트를 병합하지 않습니다.** 별개 도메인, 별개 저장소, 별개 정본 문장으로 갑니다.

**이 사이트의 정본 문장** (글자 단위 고정, 변형·요약 금지):

```
캠핑하이브 AEO는 2014년부터 전국 캠핑장 280곳을 지어 온 주식회사 캠핑하이브가 캠핑장만을 위해 만든 AI 답변 최적화(AEO·GEO) 서비스입니다.
```

이 문장은 **5곳에 글자 단위로 동일하게** 나타난다 — 푸터, 그리고 JSON-LD의
`Organization` · `LocalBusiness` · `WebSite` · `Service` 의 `description`.
앞뒤에 어떤 글자도 붙이지 않는다. 이미 완결된 한 문장이다.
`npm run verify` 가 5곳 완전 일치를 매 빌드마다 검사하며, 한 곳이라도
다르면 배포가 멈춘다.

**소재지는 두 곳이다.** 손님이 방문하는 곳과 법인 소재지가 다르다.

| 구분 | 주소 | 쓰이는 곳 |
|---|---|---|
| 공장 | 경기도 가평군 조종면 명지산로 452 | JSON-LD `Organization.address` |
| 전시장 | 경기도 포천시 내촌면 청군로 2224 (방문 상담 가능) | JSON-LD `LocalBusiness.address` · `geo.placename` |

`LocalBusiness` 는 "찾아갈 수 있는 곳"을 뜻한다. 여기에 공장 주소를 넣으면
AI가 손님에게 공장을 안내한다.

회사 홈페이지의 정본 문장은 이것과 다릅니다. `camphive/README.md` 를 보십시오.

## 현재 페이지

|---|---|
| `/` | 자리표시자 — **16섹션 시안 기반으로 통째 재구축 예정** |

**홈의 자리표시자는 하나씩 채우지 않습니다.** 별도 지시문에 따라 16섹션 구조로
새로 짓습니다. 그때까지 `src/content/index.md` 는 손대지 않습니다.

**본문에 지어낸 값이 하나도 없습니다.** 요금·통계·진단 수치·법령 문구는 실측값이
도착하기 전까지 넣지 않습니다.

> **개인정보처리방침을 지어내지 않은 이유**: 법적 효력이 있는 문서입니다.
> 그럴듯한 문장을 만들어 넣으면 실제로 하지 않는 일을 약속하는 것이 되고,
> 그 자체가 법 위반이 됩니다. 실제 수집 항목·보유 기간·위탁 업체가 확정된 뒤에 씁니다.

## 도메인 연결 절차

**현재 연결하지 않았습니다.** 두 도메인 모두 아직 조회되지 않습니다
(공개 DNS 조회 시 `SERVFAIL` — 등록은 되었으나 네임서버가 아직 응답하지 않는 상태로 보입니다).
**등록기관 관리 화면에서 네임서버가 정상인지 먼저 확인**한 뒤 아래를 진행합니다.

### ⚠ 이전 절차와 달라진 점

`aeo.camphive.kr` 은 **하위 주소**여서 `CNAME` 레코드를 썼습니다.
`aicampingmarketing.co.kr` 은 **최상위 주소(루트)** 라 **`CNAME` 을 쓰면 안 됩니다.**
루트에 CNAME을 걸면 그 도메인의 메일·기타 레코드가 전부 깨집니다. **`A` 레코드 4개**를 씁니다.

### 1단계 — 메인 도메인에 A 레코드 4개 추가

`aicampingmarketing.co.kr` 을 구입한 곳(가비아, 후이즈, 카페24 등)에 로그인 →
`DNS 관리` → **레코드 추가**를 네 번 반복합니다.

| 타입 | 호스트/이름 | 값 |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

`www` 로도 들어오게 하려면 한 줄 더 추가합니다.

| 타입 | 호스트/이름 | 값 |
|---|---|---|
| CNAME | `www` | `joung2076-cyber1076.github.io` |

**반영에 최대 24시간** 걸립니다.

### 2단계 — GitHub에 도메인 알려주기

`https://github.com/joung2076-cyber1076/camphive-aeo` 접속
→ 위쪽 `Settings` 탭 → 왼쪽 메뉴 `Pages`
→ `Custom domain` 칸에 **`aicampingmarketing.co.kr`** 입력 → `Save`

`DNS check in progress` 가 뜹니다. 1단계가 반영되면 **초록색 체크**로 바뀝니다.
바뀐 뒤 아래쪽 **`Enforce HTTPS`** 를 체크합니다.

> **1단계를 먼저 하십시오.** 순서를 바꾸면 임시 주소(`github.io`)마저
> 접속이 안 되는 상태가 몇 시간 이어집니다.

### 3단계 — BASE_PATH 제거 (빌더가 처리)

도메인이 붙으면 사이트가 주소 맨 앞(루트)에서 열리므로 하위 경로 설정이 필요 없어집니다.
`.github/workflows/deploy.yml` 에서 `BASE_PATH` 줄을 지우면 됩니다. 그 자리에 주석이 있습니다.

### 4단계 — 서브 도메인 301 (`aimarketing.ai.kr` → 메인)

> **GitHub Pages 로는 할 수 없습니다.** 저장소 하나에 붙일 수 있는 커스텀 도메인은
> **한 개뿐**이라, 두 번째 도메인을 `Custom domain` 칸에 넣으면 메인이 떨어져 나갑니다.

`aimarketing.ai.kr` 은 **도메인 등록기관의 웹 포워딩(URL 전달) 기능**으로 넘깁니다.
등록기관 관리 화면에서 `웹 포워딩` / `URL 포워딩` / `포워딩 설정` 메뉴를 찾아
아래와 같이 설정합니다.

| 항목 | 값 |
|---|---|
| 전달 주소 | `https://aicampingmarketing.co.kr` |
| 전달 방식 | **영구 이동 (301)** — 임시 이동(302)이 아닙니다 |
| 마스킹 / 프레임 | **끕니다** |

> **301이어야 하는 이유**: 302(임시)로 넘기면 AI와 검색엔진이 두 주소를 각각
> 별개 사이트로 취급합니다. 같은 본문이 두 주소에 있는 것으로 읽혀 양쪽 다
> 인용 순위에서 밀립니다. 301은 "이 주소의 신뢰도를 저쪽으로 합친다"는 뜻입니다.
>
> **마스킹을 끄는 이유**: 마스킹은 주소창만 서브 도메인으로 두고 내용을 프레임으로
> 감싸는 방식입니다. AI 크롤러에게는 **본문이 없는 빈 페이지**로 보입니다.

등록기관에 포워딩 기능이 없으면 Cloudflare 무료 플랜의 `Redirect Rules` 로 대신합니다.

|---|---|
| `npm run dev` | 빌드 + 미리보기 (`http://localhost:4321`) |

새 글 추가법, 콘텐츠 구조 규격, JSON-LD 구조는 회사 홈페이지와 동일합니다.

파일 단위로 동일하게 유지합니다.
